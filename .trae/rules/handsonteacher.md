# HandsOnTeacher (Trae)

All instructions for this repository are in `AGENTS.md` at the project root, shared by every agent. At the start of every session, read `AGENTS.md` and follow it exactly; it overrides general defaults.

Skills are mirrored in `.trae/skills/` from `.agents/skills/` (edit them only in `.agents/skills/`, then run `python3 tools/sync_skills.py`). The learner invokes one by name, for example "use create-course" or "teach-lesson continue".
